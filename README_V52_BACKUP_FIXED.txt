OsRa v52 — BACKUP FIXED / PHOTOS ONLY

هذه حزمة مبنية فوق OsRa v51_no-full-delete مع تعديل النسخ الاحتياطي فقط وبأقل تدخل ممكن في الوظائف المستقرة.

النسخ الاحتياطي:
- الحفظ الجديد يكون كملف نصي JSON بامتداد .txt وبنوع text/plain، ليظهر كملف نصي/مستند معروف عند المشاركة مثل WhatsApp.
- محتوى الملف هو JSON صالح كما هو؛ تغيير الامتداد لا يغيّر البيانات الداخلية.
- النسخ القديمة .osra والنسخ .json ما زالت صالحة للاستيراد.
- استيراد OsRa لا يعتمد على الامتداد وحده؛ يقرأ المحتوى ويتحقق من بنية النسخة.
- يبقى الملف واحدًا ولا يحتوي الملفات الأصلية للصور.
- يحتفظ بكل بيانات OsRa، وفهرس الربط، مفاتيح matchKey/contentKey/fingerprint، روابط المصادر، والمعاينات المصغرة المخزنة.
- تم جعل JSON مضغوطًا سطرًا واحدًا لتقليل الحجم وزمن الإنشاء دون حذف البيانات.
- تحويل المعاينات إلى Base64 يستخدم FileReader، مع تقليل فواصل الانتظار أثناء التصدير لتحسين السرعة.

الأذونات:
- صلاحية ملف النسخة المحفوظة لا تُطلب في كل عملية حفظ. يتم الاستعلام عنها أولًا، ولا يُعاد طلبها إلا إذا فقدها Android/المتصفح.
- صلاحية مجلد الصور لا تُمسح بسبب ملف مفقود أو مسار قديم. تُمسح فقط عند NotAllowedError أو SecurityError، وبالتالي لا تظهر نافذة إذن لكل صورة.
- لا يمكن لأي Web App تجاوز قرار Android/Chrome إذا سُحبت الصلاحية من النظام؛ عندها يلزم منحها مرة أخرى.

الاستعادة:
- الاستيراد يقبل .txt + .osra + .json.
- الاستعادة الكاملة لا تحذف أصول الصور الأصلية من الجهاز.
- قبل الاستعادة توجد نسخة أمان محلية.
- الدمج يحتفظ بالبيانات المحلية ويطابق الصور بالـ id ثم matchKey ثم contentKey ثم fingerprint.
- الربط عبر تغيير المسار/اسم الملف يبقى معتمدًا على مفاتيح المحتوى القوية.

التحديث والكاش:
- تمت زيادة إصدار كاش Service Worker إلى v52-backup-fixed حتى تصل ملفات هذه الحزمة بدل نسخة v51 القديمة.

ملاحظة:
- تم فحص البنية البرمجية والامتدادات والوظائف ذات الصلة محليًا. لم يتم تشغيل اختبار فعلي داخل WhatsApp أو على جهاز Android حقيقي في هذه البيئة.
