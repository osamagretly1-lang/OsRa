OsRa — FINAL PHOTOS ONLY — RELEASE

هذه النسخة مبنية على v30 المستقرة وتحافظ على قاعدة البيانات نفسها (OsRaDB، الإصدار 1) دون ترقية أو حذف للبيانات.

- الصور فقط تدخل الفحص الجديد وتظهر في التطبيق.
- الصور الأصلية تبقى في المجلد المحلي ولا تُنسخ إلى GitHub أو داخل التطبيق.
- المعاينات المحلية خفيفة: 320px كحد أقصى وبصيغة WebP بجودة ابتدائية 78%، مع سقف 160KB للمعاينة.
- عند فتح الصورة تظهر المعاينة فورًا ثم تُستبدل بالصورة الأصلية من المجلد المرتبط.
- الخروج من عارض الصورة يصفر التكبير والتحريك ويفرغ رابط الصورة الكبيرة من الذاكرة.
- التكبير بالإصبع/الأزرار يصل حتى 6x، مع إمكانية السحب عند التكبير وإعادة 1:1.
- يمكن ربط أكثر من مجلد صور مستقل؛ كل مجلد إضافي يُفحص وحده فقط، دون إعادة فحص المكتبة الأصلية كلها. إذا كان اسم المجلد الجديد مطابقًا لمصدر موجود، يظهر اختيار صريح للدمج أو الفصل.
- إذن القراءة مرتبط بكل مجلد مصدر، ويُستخدم لكل الصور داخله بدل طلب إذن لكل صورة. قد يعيد المتصفح طلب التأكيد بعد إعادة فتح التطبيق بحسب سياسة صلاحياته.
- الفحص يحفظ نقطة تقدمه دوريًا في مساحة التطبيق المحلية، ويستطيع الاستكمال بعد إغلاق/إعادة فتح التطبيق عند توفر إذن المجلد.
- عند تعذر التنفيذ أثناء إيقاف الشاشة، لا يمكن للمتصفح ضمان استمرار JavaScript في الخلفية؛ لذلك تُحفظ نقطة التوقف ويُستكمل الفحص عند عودة التطبيق.
- استيراد النسخة الاحتياطية يحتفظ بسجلات الصور وروابط الألبومات، ثم يستطيع الفحص داخل المجلد المختار وكل مجلداته الفرعية مطابقة الصور حتى مع تغيير الاسم أو الترتيب، اعتمادًا على مفاتيح محتوى/بصمة محفوظة. لا يملك المتصفح إذنًا لفحص كل مساحة تخزين الهاتف تلقائيًا؛ يجب اختيار مجلد يسمح به المستخدم.
- إعادة السماح بالصور المستبعدة تُعيدها للفهرس ثم تبدأ إعادة فحص للمصادر المتأثرة فقط؛ عند عدم وجود صور مستبعدة يبقى الزر معطلًا.
- العدادات والمواعيد ميزة اختيارية مستقلة عن الأحلام: يمكن إضافة أي موعد، جعله متكررًا سنويًا، واختيار إظهاره في الرئيسية أو إبقائه داخل الإعدادات.
- بيانات الذكريات، الألبومات، الترتيب، الإخفاء، الاستبعاد، الأحلام، الآيات، الرسائل، المحطات، العدادات، والنسخ الاحتياطية محفوظة.
- لا يتم مسح IndexedDB أو localStorage أو الملفات الأصلية.

- الفحص العادي لا يعيد الصور المستبعدة؛ إعادة إدراجها تتم من الإعدادات فقط عبر «السماح بها وإعادة فحصها».
- الفحص قابل للإيقاف والاستكمال مع حفظ نقطة التوقف.
- يوجد تحديد بالسحب بجانب التحديد المرقّم، مع حفظ موضع التمرير.
- أصول الصورة الواحدة يمكن أن تكون في أكثر من مجلد، مع بقاء سجل الصورة واحدًا.
- «ربط الأصول في كل المجلدات» يبحث داخل المجلدات المرتبطة فقط ويطابق سجلات النسخة الاحتياطية دون إضافة صور جديدة.
- «كشف التكرارات» يعرض الصور فعليًا ويطلب اختيارك؛ لا يحذف الأصل من الهاتف ولا يحذف تلقائيًا.
- الصور المصغرة 320px/WebP بنسبة 78% وبحد 160KB، والأصل المحلي هو المستخدم للعرض والمشاركة.
