تركيب OsRa R81 يدويًا

1) احتفظ أولًا بنسخة من ملفات مستودع GitHub الحالية، واحتفظ أيضًا بملف ZIP الخاص بـ R80 كنسخة رجوع.
2) فك ضغط OsRa_v122_R81_MESSAGE_LIBRARY_MASCOTS_NIGHT.zip.
3) ارفع محتويات المجلد المستخرج إلى جذر مستودع OsRa نفسه، أي المجلد الذي يحتوي index.html، مع استبدال الملفات ذات الأسماء نفسها.
4) ارفع مجلد assets كاملًا كما هو. لا تحذف ملفات أصول قديمة، ولا ترفع ملف ZIP نفسه بدل محتوياته.
5) لا تمسح بيانات الموقع أو بيانات المتصفح، ولا تستخدم Clear site data. قاعدة البيانات ما زالت OsRaDB / version 100 ولا تحتاج إلى ترحيل.
6) بعد نشر GitHub Pages افتح الموقع من جديد. رقم بناء Service Worker تغيّر إلى R81؛ سيطلب المتصفح تحديث ملفات التطبيق. كاش الصور الأصلية المنفصل OsRa-CloudOriginals-v1 لا يُمسح ضمن تحديث كاش التطبيق.
7) افتح الإعدادات > مكتبة الرسائل. ستجد الرسائل الأصلية والرومانسية ورسائل التطبيق الكوميدية في مجموعات منفصلة. فعّل فقط الرسائل الكوميدية التي تريدها، ثم اضغط «حفظ» أسفل الإعدادات. افتح «تعديل» بجانب أي رسالة لتغيير النص أو العرض أو الحركة أو الشخصية المصاحبة.
8) في الإعدادات > تحكم الشخصيات، اختر الشخصية الثابتة أو العشوائية، ومكانها وحركتها. موكب شاشة البداية مستقل عن الشخصيات داخل الرسائل.
9) في بطاقة الرسالة الليلية، يكون الوقت الافتراضي 23:00–01:00. يمكن تعديل النص والوقت أو إيقافها، ثم الحفظ.
10) لمزامنة Drive: أدخل OAuth Client ID ومعرّف المجلد والبريد المطلوب. اختر الحساب من نافذة Google. لا تبدأ المزامنة إلا إذا ظهر البريد المطابق في التطبيق. نجاح OAuth النهائي يعتمد على إعدادات Google Cloud وصلاحيات المجلد.

تنبيه: لا تمسح بيانات الموقع أو IndexedDB أثناء تحديث الملفات. ZIP التطبيق لا يحتوي على مكتبة الصور الشخصية أو قاعدة بيانات الهاتف؛ بياناتك المحلية تبقى في المتصفح ما دمت لا تمسحها.
