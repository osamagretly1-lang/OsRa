OsRa v47 — BACKUP STABLE

إصلاح الحفظ:
- زر «حفظ نسخة الآن» لم يعد يستدعي نافذة اختيار مكان الحفظ بعد عملية await، لتجنب فقدان صلاحية user activation على Android.
- إذا كان هناك ملف ثابت محفوظ وله إذن صالح، يتم تحديثه مباشرة.
- وإلا يتم إنشاء تنزيل مباشر لملف OsRa_Backup_YYYY-MM-DD.osra.
- تم تمديد عمر رابط التنزيل إلى 60 ثانية لتفادي مشاكل بعض متصفحات Android.
- بعد الكتابة في ملف ثابت يتم التحقق من أن الملف غير فارغ.

الاستيراد:
- يقبل .osra و .json.
- الاستعادة الكاملة تسترجع بيانات OsRa وفهرس الصور والمعاينات الموجودة في النسخة.
- لا تحذف الصور الأصلية من الهاتف.
- ربط الأصول عبر matchOnly لا ينشئ صورًا أو ألبومات جديدة.

الإصدار:
- إصدار التطبيق: 47-backup-stable.
- DB_VERSION=2 هو إصدار مخطط IndexedDB الداخلي فقط، وليس إصدار التطبيق. لم يتم تغييره لتجنب أي ترحيل أو فقد بيانات.
