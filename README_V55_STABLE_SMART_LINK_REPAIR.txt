OsRa v55 — Stable Smart Link Repair

هذا الإصدار تعديل صغير على v54: لا يفحص المكتبة عند فتح التطبيق ولا يعيد الربط تلقائيًا. الرابط المحفوظ يبقى محفوظًا، والأخضر يبقى أخضر حتى محاولة فتح الأصل/فحص الألبوم. عند فشل المسار فعليًا أثناء فتح الصورة، يحول OsRa ذلك الرابط فقط إلى حالة missing ويحفظ الحالة، ثم يعرض مخطط مصادر البحث الذكي للمصدر الأعلى نجاحًا فالأدنى. أخطاء الصلاحيات لا تُسجل كفقدان للملف. ترتيب المصادر وإحصاءات نجاحها مستمرة ومحفوظة. لا يتم حساب بصمات إضافية عند التشغيل العادي.
