OsRa v122 — R52 MOTION REFINED (test candidate)

Based directly on OsRa R51; no change to IndexedDB schema version 100.

R52 motion corrections:
- Removed detached hand emoji overlays from page turns. The correct full-body pose art must supply connected arms; when pose art is absent, only the character-body lean is shown rather than a fake floating hand.
- Locked Osama to the left edge and Rania to the right edge throughout page turning, and added a token plus tracked cleanup timers so rapid flips cannot let an old timer erase a newer scene.
- Page-turn characters still appear together on each actual flip, as requested earlier, but only for the page-turn interval and from opposite edges.
- Replaced one repeated dance transform for the entire celebration with a multi-phase sequencer: slow dance, shuffle, joyful bounce, hug sequence, and optional acrobatic/lift phases. Lift/acrobatic phases require all paired pose assets; if absent the choreography safely falls back to synchronized bounce.
- Added named pose slots for the later approved personalized sprite art.

Other R51 features are preserved: quick/visual linking, thumbnail recovery, scan skip/pause/cancel, interactive linking reports, source list collapse, daily-photo selection, per-message presentation/motion settings, two-step excluded-image restore, camera membership cleanup, existing celebration effects and ribbon toggle.

Important: the real personalized base characters and pose frames are not included yet, so connected hand/arm articulation and a convincing carry-spin-lower cannot look complete until those image assets are produced and installed. Use as a separate test build; the old copy and its data should be preserved.
