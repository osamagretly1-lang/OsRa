OsRa v122 — R51 CHOREOGRAPHY / CUSTOM SURPRISES TEST BUILD

This candidate is based on the supplied R50_LINK_SCAN_PHOTO_FESTIVE build. The pre-change R50 snapshot is available separately as OsRa_v122_R50_BACKUP_BEFORE_R51.zip.

R51 prepares two separate character movements: (1) opening celebration where Osama and Rania enter from opposite sides, approach “احتفال”, pause as if reading it, step back, and dance; (2) page-turn movement where both appear at opposite edges and lean/push toward the page with opposing hands. The base character images and optional action-pose images are not yet included; those transparent images will be added after the user's personalized character art is generated.

R51 also improves daily photo selection, per-message presentation and motion settings, the saved-message manager, two-stage excluded-photo restoration confirmation, camera album membership cleanup, and celebration-ribbon behavior. IndexedDB remains at version 100.

Testing completed on this candidate: JavaScript syntax checks, HTML parsing/duplicate-ID checks, CSS parser checks, static feature checks, ZIP integrity checks, and isolated unit tests for daily-photo consistency and camera membership cleanup.

The available environment blocked Chromium navigation with ERR_BLOCKED_BY_ADMINISTRATOR. Therefore browser/device end-to-end behavior, camera-folder edge cases, live filesystem permissions, IndexedDB on the user's phone, and visual likeness/motion must still be checked on the phone before replacing the current installation. Do not treat static validation as proof of full device acceptance.
