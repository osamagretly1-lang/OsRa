تثبيت OsRa R80

1) احتفظ بنسخة ZIP السابقة R79 ولا تحذف ملفاتك أو مجلد الصور.
2) فك ضغط OsRa_v122_R80_GARDEN_OPENING_ACCOUNT_PICKER.zip.
3) ارفع محتويات المجلد إلى نفس مستودع OsRa/فرع GitHub Pages، مع السماح باستبدال index.html وapp.js وstyle.css وsw.js فقط لأنها ملفات التطبيق المحدثة، وإضافة assets/couple-garden. لا ترفع ZIP داخل مسار الموقع بدل محتوياته.
4) افتح الموقع بعد اكتمال GitHub Pages، ثم حدّث الصفحة تحديثًا كاملًا. قد تحتاج إغلاق التطبيق وإعادة فتحه لتفعيل Service Worker الجديد.
5) من الإعدادات > الرسائل الرومانسية والاحتفالات يمكنك اختيار نموذج الحديقة والزهور، منفردًا أو بالتتابع مع النماذج القديمة.
6) من الإعدادات > تحكم شاشة البداية يمكنك إظهار/إخفاء موكب الشخصيات الستة والشريط الأحمر بشكل مستقل.
7) من الإعدادات > Google Drive: احفظ OAuth Client ID ومعرّف المجلد. استخدم «اختيار / تغيير الحساب فقط» لاختيار الحساب الذي سيظهر بريده في الإعدادات، ثم «مزامنة الآن» أو «اختيار الحساب والربط الآن».

تنبيه مهم: إذا لم تفتح نافذة اختيار الحساب، تحقق من السماح بالنوافذ المنبثقة للموقع ومن أن Authorized JavaScript origins يحتوي عنوان OsRa الفعلي، ومن أن OAuth Client ID من نوع Web application. لا تُدخل Client Secret في التطبيق.
