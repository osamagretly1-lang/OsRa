- البحث يفتح العنصر نفسه ويعلّمه: الرسالة/الحلم/الآية تظهر في مكانها داخل القسم الصحيح مع تمييز واضح، والرسائل تعرض كلمة البحث مظللة داخل النص.
- «← نتائج البحث» يعيد نفس النتائج المحفوظة وكلمة البحث والفلتر، بدون إعادة تنفيذ البحث.
- البحث يدعم «كل النتائج» أو «صور فقط». في وضع «صور فقط» يمكن البحث باسم الصورة ومسارها وتاريخها واسم/مكان/وصف الألبوم المرتبط، لكن النتائج تظل صورًا فقط.
- نتائج البحث تشمل كذلك الصلوات/الأمنيات والمحطات، وكل عنصر يفتح في مكانه الصحيح.
- مراجعة الصور الجديدة: اختيار أي صور متفرقة أو مجموعة كاملة، ثم اختيار أي ألبوم، وبعد التنفيذ تبقى شاشة المراجعة مفتوحة وتعرض المتبقي فقط حتى آخر صورة.
- إغلاق نافذة مراجعة الصور ثم فتحها لا يصفر التحديد المعلق الحالي.
