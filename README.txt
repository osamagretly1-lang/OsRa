OsRa — Our Story
==================

هذه نسخة أولية عملية من تطبيق OsRa، مصممة لتجربة البنية الأساسية قبل إدخال مكتبة الصور الكبيرة.

أهم ما فيها
-----------
- تصميم كتاب ورقي RTL مع تأثير قلب صفحات 3D بين الأقسام.
- الصفحة الرئيسية: رانيا ♥ أسامة / قصتنا وصداقتنا.
- مكتبة صور خارجية باسم OsRa Photos.
- فهرسة مجلدات الصور تلقائيًا كذكريات.
- صور مصغرة محلية، مع محاولة فتح الأصل من المجلد.
- بحث في الذكريات والرسائل والأحلام والآيات.
- صورة اليوم ثابتة لكل يوم.
- "في مثل هذا اليوم".
- حساب المدة منذ البداية والخطوبة.
- المناسبات القادمة.
- أحلامنا مع نسبة إنجاز.
- آيات + آية اليوم + صلوات/أمنيات.
- رسائلنا المميزة ⭐.
- دعم Web Share Target لمحاولة استقبال نص مشاركة من واتساب بعد تثبيت OsRa.
- نسخ احتياطي للبيانات والـphoto manifest بدون نسخ الصور الأصلية.
- تشخيص سريع للصلاحيات والتخزين.

طريقة الاختبار
--------------
1) افتح OsRa من HTTPS (مثل GitHub Pages) أو localhost. لا تعتمد على file:// لاختيار المجلد.
2) على الهاتف استخدم Chrome حديث.
3) أنشئ مجلدًا باسم OsRa Photos وضع داخله مجلدات مثل:
   الخطوبة/
   أول خروجة/
   الكورنيش/
   مؤتمر 2025/
4) لا تبدأ بالـ2000 صورة. اختبر أولًا بـ50–200 صورة.
5) من "ذكرياتنا" اختر "ربط / استيراد OsRa Photos".
6) انتظر الفهرسة.
7) افتح ألبومًا واضغط صورة ثم جرّب السابق/التالي.
8) أغلق OsRa وافتحه مجددًا واختبر "تشخيص" و"فتح الصورة الأصلية".
9) جرّب الرسائل: في واتساب شارك نص الرسالة إلى OsRa بعد تثبيته، أو أضفها يدويًا.
10) بعد نجاح الاختبار، وسّع المكتبة إلى 2000 صورة.

الخصوصية
---------
- الصور الأصلية لا تذهب إلى GitHub ولا إلى خادم.
- التطبيق يخزن بياناته محليًا في IndexedDB.
- الـbackup لا يحتوي الصور الأصلية.
- إذا فقدت صلاحية المجلد يمكن إعادة ربطه من الإعدادات.

ملاحظة المتصفح
---------------
الوصول المباشر للمجلد يعتمد على File System Access API، وهو يحتاج سياقًا آمنًا (HTTPS/localhost) وليس مدعومًا في جميع المتصفحات.
