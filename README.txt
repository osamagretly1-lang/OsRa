OsRa v59 — Final Audited Release

هذه الحزمة مبنية على خط OsRa v58 التراكمي، مع آخر تعديل مطلوب فقط:
- نتائج بحث الصور تُجمع حسب الألبوم بدل عرض كل صورة كنتيجة مستقلة.
- الضغط على نتيجة الألبوم يفتح الألبوم، والرجوع يعيد نتائج البحث والاستعلام والفلتر.

الحماية والربط:
- الصور الأصلية لا تُنسخ إلى GitHub ولا تدخل داخل ملف النسخ الاحتياطي.
- النسخ الاحتياطي النصي OsRa-Text-JSON-v1 يحفظ البيانات، معاينات صغيرة، ومراجع الأصول.
- الربط يستخدم مفاتيح سريعة للعثور على المرشح، ثم SHA-256 كاملة للتحقق النهائي عند فحص الأصل/فتحه.
- المسار والحجم وتاريخ التعديل عوامل مساعدة، وليست وحدها إثباتًا لهوية الأصل.
- إذا كانت الصورة معدلة/مضغوطة/مقصوصة ولا تطابق الأصل حرفيًا، لا يتم ربطها تلقائيًا؛ يمكن استخدام الاسترجاع البصري اليدوي.

الوظائف المتراكمة المحفوظة من الإصدارات السابقة تشمل البحث الدقيق، مراجعة الصور الجديدة، الربط الذكي متعدد المصادر، التحقق من الأصول، الاسترجاع الذكي، النسخ الاحتياطي والاسترجاع ونسخة الأمان المحلية، الأحلام والآيات والصلوات والرسائل والتواريخ والألبومات، مع التشغيل دون رفع الصور الأصلية إلى السحابة.

هذه الحزمة تحتوي ملفات OsRa فقط.
